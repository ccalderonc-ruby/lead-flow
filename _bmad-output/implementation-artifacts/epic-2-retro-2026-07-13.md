## Challenges

- Inertia validation remount losing submitted form values deferred in **both** 2.2 and 2.3 — risk of copying into Epic 3 task/note forms.
- Lead detail previews are intentional read-only shells; Epic 3 ACs expect CTAs (New Task, notes) on detail.

- Epic 2 not yet merged to `dev` — still feature-branch only at session close.

## Key insights

1. Explicit layering (list redirect until show; shared form when edit landed) reduced thrash.
2. Review patches caught real product bugs (company-country checkbox, non-numeric value, date TZ) — keep that loop.
3. Decide sticky UX debt **once** before proliferating form controllers (Epic 3).
4. Detail page is a hub; next epic’s value is wiring actions into it, not more counts.
